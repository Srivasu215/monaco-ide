The Story & Architecture

Why We Built Monaco IDE

Throughout the development of our JSON transformation pipelines (primitive, 1D collections, and 2D table renderers), we constantly faced friction switching back and forth between heavyweight desktop IDEs, terminal processes, and separate browser windows.

Earlier experiments in legacy editor setups grew cluttered with conflicting CSS libraries and heavy runtimes. We asked a fundamental question: Why not treat Monaco as our first-class, primary workspace with direct OS file integration?

Monaco IDE V5 solves the final frontier of browser IDEs: asset resolution. When previewing local HTML pages that reference relative CSS stylesheets (like ./css/style.css) and images, the Virtual Workspace Asset Resolver extracts them directly from your local project directory handle and inlines them into the sandboxed preview—producing a 100% pixel-perfect, fully-styled live preview without requiring a local web server!

Virtual Asset Resolver

Auto-resolves relative <link rel="stylesheet">, scripts, and images directly from your workspace folder into the live preview.

Event Bus Architecture

Decoupled pub/sub message broker (core/eventBus.js) cleanly separating explorer, tabs, preview, and status bar modules with zero callback spaghetti.

Quick Open Palette (Ctrl+P)

Fuzzy search across all workspace files and open tabs. Keyboard navigation with instant switching.
