The Story & Architecture

Why We Built Monaco IDE

Throughout the development of our JSON transformation pipelines (primitive, 1D collections, and 2D table renderers), we constantly faced friction switching back and forth between heavyweight desktop IDEs, terminal processes, and separate browser windows.

Earlier experiments in legacy editor setups grew cluttered with conflicting CSS libraries and heavy runtimes. We asked a fundamental question: Why not treat Monaco as our first-class, primary workspace with direct OS file integration?

Monaco IDE V4 completes the transformation into a full desktop IDE replacement. Powered by the File System Access API (showDirectoryPicker and createWritable), you can now open entire project directories, navigate files from a collapsible tree sidebar (Ctrl+B), edit multiple files in tabs, toggle live split preview (Ctrl+\), and persist changes directly back to your local files with Ctrl+S.

Workspace Folder Explorer

Open entire local directories with showDirectoryPicker. Browse recursive trees and toggle the sidebar with Ctrl+B.

Live Split Preview (Ctrl+\)

Real-time split pane rendering for HTML (sandboxed iframe), formatted JSON trees, and Markdown documents as you type.

Studio Status Bar & Controls

22px status bar with line/column tracking, language indicator, and quick toggles for Word Wrap (Alt+Z) and Monaco Minimap.
